# Estudio

Material y avance de las sesiones con la skill `estudiar`.

```
estudio/
  <ramo>/                 mate2, micro, contabilidad, comunicacion, ingles4
    material/             PPT/PDF de clases, ejemplos, ayudantías, pruebas anteriores
    <evaluacion>/         ej.: control-2
      sesion.md           avance, errores y pruebas ya rendidas (la skill lo actualiza)
      mega_resumen.html   el resumen final "como siempre"
```

Para empezar: escribe `/estudiar` o simplemente "quiero estudiar para el control 2 de micro".
